36. FOLLOW-UP AUTOMATION
============================================================

Apps Script worker processes follow-ups.

Only process:

status = SCHEDULED

and:

scheduled_at <= NOW()

Before sending:

1. Check if lead has replied.
2. Check if company is suppressed.
3. Check if another follow-up was already sent.
4. Check if user cancelled it.
5. Check if maximum follow-up limit is reached.

If reply exists:

automatically change:

FOLLOW_UP_STATUS = SKIPPED

REASON = REPLIED

Do NOT send an unnecessary follow-up after a reply.
